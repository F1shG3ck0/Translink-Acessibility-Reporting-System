What routes have accessible stops?

Below shows a table of every route, the number of stops, and the percentage that are accessible. The goal of this report is to identify which routes need to have accessibility improvements.


Accessibility by Route

Route Name Total Stops Accessible Stops % Accessible

This report shows how accessibility is distributed across individual routes by comparing the total number of stops on each service with the number that offer accessibility features. The results reveal which routes provide strong, consistent accessibility coverage and which rely on only a small number of accessible stops. Routes with low percentages may create challenges for passengers who depend on accessible boarding points, potentially limiting their ability to travel independently or reliably. The report therefore supports targeted improvements by highlighting specific routes where additional accessible stops would significantly enhance network inclusivity.
