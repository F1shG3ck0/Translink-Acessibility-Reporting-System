Which stops should be prioritised for accessibility improvements?

This report identifies stops that may require priority accessibility improvements.
It combines accessibility complaint levels with the number of accessibility-related stop features currently available.
Stops with more accessibility complaints and fewer accessibility features are given a higher priority level.
This will help in the identification of stops which need immediate attention to improve accessibility.
